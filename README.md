# Random Quote Machine

## Introduction

A simple and responsive Random Quote Machine built using React, JavaScript, CSS, and Vite. It displays inspirational quotes with their authors and allows users to generate new quotes and share them on Twitter.

## Features

- Display a random quote when the page loads.
- Generate a new quote using the New Quote button.
- Display the quote's author.
- Share the current quote on Twitter.
- Responsive and user-friendly design.
- Simple and attractive interface.

## Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- Vite

## How to Use

1. Open the Random Quote Machine in your browser.
2. Read the displayed quote and author.
3. Click **New Quote** to display another quote.
4. Click the Twitter icon to share the current quote.
